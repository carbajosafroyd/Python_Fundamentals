# String Concatenation

To concatenate, or combine, two strings, use the `+` operator.

## Combine Two Strings

Merge variables `a` and `b` into variable `c`:

```python
a = "Hello"
b = "World"
c = a + b
print(c)
```

## Add a Space Between Strings

Add a space between the strings by including a space inside a string literal:

```python
a = "Hello"
b = "World"
c = a + " " + b
print(c)
```
